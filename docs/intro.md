# Introduction

[Back to docs](./index.md)

## Core Features & Integrations

### Framework & Documentation

- NestJS framework integration
- Swagger API documentation
- CLI tools for code generation
- E2E testing with Jest and Supertest
- API versioning support with decorators

### Database & Caching

- SQL database support via Sequelize ORM
- MongoDB support via Mongoose
- Redis for caching and JWT tokens
- Database seeding functionality

### Authentication & Security

- Passport.js authentication
- Multiple auth strategies:
  - JWT
  - Local auth
  - Social logins (Google, Facebook, Apple)
  - Firebase auth
- Class validator for API validations

### Infrastructure

- Environment-based configuration
- Logging system
- Cron job support
- WebSocket integration
- Microservices architecture
- Static file serving
- HBS template rendering

### Third-Party Services

- AWS (S3)
- Firebase (Auth, Messaging)
- Email (Nodemailer, Sendgrid)
- SMS (Twilio)
- Payments (Stripe)
